# 🤖 PragyanAI Conversational Sales & FAQ Assistant

An AI-powered RAG (Retrieval-Augmented Generation) chatbot built using:

- Streamlit
- LangChain
- Groq (Llama 3.3 70B)
- HuggingFace Embeddings
- FAISS Vector Store

## Features

- Multiple AI Personas
- PDF Knowledge Base
- Excel Knowledge Base
- Conversation Memory
- Semantic Search using FAISS
- Upload new PDFs/Excel files
- Streamlit UI

## Technologies

- Python
- Streamlit
- LangChain
- FAISS
- HuggingFace
- Groq API

## Run Locally

```bash
pip install -r requirements.txt

streamlit run app.py
```
